Aviso de privacidade

Este texto é um modelo inicial: o responsável pelo serviço deve revisar e indicar um contato antes do lançamento ao público.

Quais dados usamos?

Nome, e-mail, telefone, endereço da visita, referências de localização, informações dos animais, observações e pedidos de visita.

Para que são usados?

Para criar a conta, organizar visitas, avaliar disponibilidade, entrar em contato sobre solicitações e realizar cuidados pet contratados.

Quem acessa?

Cada cliente autenticado visualiza seus próprios dados e solicitações. O profissional autorizado visualiza os cadastros necessários ao atendimento. O calendário público mostra apenas se um horário está livre, pendente, confirmado ou bloqueado.

Onde são guardados?

Em um banco de dados Supabase escolhido pelo responsável pelo serviço. O código público do GitHub não deve conter cadastros ou senhas.

Seus direitos

Você pode solicitar acesso, correção ou exclusão dos dados ao responsável pelo serviço, observadas as obrigações legais aplicáveis.

Contato do responsável

Antes de publicar: substituir este trecho pelo canal de atendimento e identificação do responsável pelo tratamento dos dados. Definir também prazo de retenção e procedimento de exclusão.
